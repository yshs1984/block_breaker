# ブロック崩し

インストール不要のブロック崩しゲームです。`index.html` / `game.js` / `tutorial.js` の3ファイルだけで完結します。
背景は星がまたたく宇宙っぽい見た目です。

## 遊び方

`index.html` を**ダブルクリックしてブラウザで開く**だけです（サーバや npm は不要。ビルドも不要です）。

- **← →**（左右キー）… パドルを左右に動かす
- **↑ ↓**（上下キー）… パドルを前後に動かす（前は画面下側1/3のラインまで、行き過ぎません）
- **スペースキー** … スタート／もう一度／次のステージへ
- **Tキー**（スタート画面のみ）… チュートリアル（練習モード）を開始
- **Pキー** … ポーズ／再開の切り替え
- **Shiftキー（押しっぱなし）** … 力を溜める。溜まった状態でパドルに当たると、次のブロックを**2つまで反射せず連続で破壊**できる（パワーヒット）。発動後は約10秒のクールダウンがある
- ブロックを全部消すと**ステージクリア**。次のステージは少し速く、ブロックが1行増えます。
- ボールを下に落とすと**残機（♥）が1つ減り**、0でゲームオーバーです。
- スコアが2000点に達するごとに**残機が1つ増えます**（`CONFIG.lifeBonusScore`で調整可能。コンボ導入でスコアが伸びやすくなった分、旧1000点から引き上げています）。
- パドルから離れてから戻ってくるまでの間に**連続でブロックを壊すとコンボ**になり、コンボ数が伸びるほど1個あたりのスコアが増えていきます（1個目+10点、2個目+15点、3個目+20点…）。コンボが2以上の間はパドルの少し上に「COMBO x◯」と表示され、5以上・10以上で文字が大きく派手な色に変わっていきます。貫通・パワーヒットで一気に連続破壊すればさらに大きなコンボが狙えます。
- 画面上部中央には「STAGE 1  1:23」のように、そのステージの経過時間も表示されます。
- **ゲームオーバー画面**には、今回のプレイでの**ステージ別クリアタイム**と、このブラウザ内に保存された**ベスト5ランキング**（スコアが高い順、各順位のステージ別タイム付き）が表示されます。ランキングは`localStorage`によるローカル保存で、他の人と共有されることはありません。

## 邪魔な障害物（ステージが進むと登場）

- **ステージ3以降**: 普通のブロックに紛れて、**見た目では区別できない「壊れないブロック」**が混ざります。一度当たると灰色になって正体を現しますが、それ以降も消えずに残り続けます（貫通アイテムやパワーヒット中でも素通りできません）。2ステージごとに1個ずつ増え、最大10個まで（ステージ21あたりで頭打ち）。壁際の列や、壊れないブロック同士が隣り合う配置にはならないようにしています（隙間にボールがはまって反射がループし続けるのを防ぐため）。
- **ステージ5以降**: 画面中央あたりに、左右にフラフラ揺れながら一定時間だけ漂う**紫色の障害物**が定期的に現れます。ボールが当たっても壊れず跳ね返り、しばらくすると自然に消えます。

## ボスステージ

**5ステージごと**（5, 10, 15…）は通常のブロックの代わりに、画面上部を動き回る**大きなボスブロック**が1体だけ現れます。

- ボスは左右に動きますが、**不規則に向きを変える**うえ、**ときどき下（プレイヤー側）へグッと突っ込んで戻ってきます**。単調に往復しないので、ボールと同じ動きになって同じ場所で当たり続ける…といった状況になりにくくしています。
- ボスにはHPがあり、当てるたびにHPバーが減っていきます（見た目もその瞬間だけ白く光ります）。当たったボールは跳ね返り（壊れないブロックと同じ扱いで、貫通・パワーヒット中でも素通りできません）、通常のブロックと同じ確率でアイテムも落とします。
- **パワーヒット中にボスへ当てると、通常より大きなダメージ**が入ります。溜め撃ちを駆使して一気にHPを削りましょう。
- HPが0になるとボスを撃破し、**大きめのスコアボーナス**を獲得して次のステージへ進めます。
- ボスを倒すたびに、次に現れるボスは**HPが増え・動きも速くなり**、少しずつ手ごわくなっていきます（どちらも上限あり）。
- ボスは**数秒おきに小さなブロックを周囲に放出**します。放出されたブロックは通常のブロックと全く同じ扱い（壊すとスコア・コンボ・アイテムドロップあり）で、ボス本体を狙う合間の得点源やアイテム調達に使えます（場に残っているブロックが多いときは放出をお休みします）。誘導（ホーミング）アイテムは、ボスステージ中はボス自身を追いかけます。
- 回が進むと、ボスの周りに**フラフラ漂う障害物**も増えていきます（ステージ10で1つ、15で2つ…上限あり）。ボール当てのコースをさらに邪魔してきます。
- 通常ステージのフラフラ障害物（時間で消えるタイプ）はボス戦中は出ません（上記はボス戦専用の常設タイプ）。

> ステージが進むごとの速度上昇は緩やかです（旧バージョンではステージ5以降が急激に難しくなりすぎたため調整しました）。

> 音は最初にキーを押した瞬間に有効になります（ブラウザの仕様）。

> スタート画面はシンプルに「スペースキーで本編スタート／Tキーでチュートリアル」の案内だけです。詳しい操作の
> 全項目一覧はポーズ画面（Pキー）で見られます。ページ内に別枠の説明文は無いので、画面が小さくてもスクロール
> 不要でプレイできます。操作をど忘れしたら、Pキーでいつでも見返せます。

## チュートリアル（練習モード）

初めての方は、スタート画面で**Tキー**を押すとチュートリアルが始まります。左右・前後移動、ボールの打ち返し、
ブロック破壊、アイテムの受け取り、溜め撃ち、ポーズまで、実際に操作しながら一通り体験できます。
各手順は該当する操作をすると自動で次に進みます（説明だけの画面ではスペースキーで次へ）。

- チュートリアル中はボールを落としても**残機は減りません**（安全に練習できます）。
- ブロックを壊す手順・アイテムを取る手順は、詰まらないように配慮されています。アイテムを取り損ねても
  すぐ次の1個が降ってきますし、ブロックはこの手順に入るタイミングで毎回きちんと用意されます。
- **Escapeキー**でいつでも中断してスタート画面に戻れます。
- 最後まで終えると、そのまま本編のステージ1が始まります。

## アイテム

ブロックを壊すと、ときどきアイテムが落ちてきます。**パドルで受け取る**と効果が出ます。

| 表示 | 名前 | 効果 |
| --- | --- | --- |
| **W** | パドル拡大 | 一定時間バーが長くなる（良い） |
| **S** | スロー | 一定時間ボールが遅くなる（良い） |
| **♥** | 残機+1 | 残機が1つ増える（良い、他のアイテムより出現率がかなり低いレアアイテム） |
| **$** | ボーナス | スコア +100（良い） |
| **N** | パドル縮小 | 一定時間バーが短くなる（悪い） |
| **F** | ボール加速 | 一定時間ボールが速くなる（悪い） |
| **P** | 貫通 | 一定時間、ブロックを跳ね返さずにすり抜けて連続で壊せる（良い）。壁・パドルへの反射は通常どおり |
| **B** | 大玉 | 一定時間ボールが大きくなる（良い）。当たり判定も大きくなる |
| **↑** | パドル加速 | 一定時間パドルの移動速度が上がる（良い） |
| **↓** | パドル減速 | 一定時間パドルの移動速度が下がる（悪い） |
| **★** | スター | 一定時間、ボールが画面下に落ちてもミスにならず跳ね返る＋ボールが速くなる（良い） |
| **◎** | 誘導 | 一定時間、ボールが自動で近くのブロックへ向かって少しずつ曲がる（良い）。効果が切れた瞬間、ボールの軌道はパドルの方向へ自動で補正されます（真横に近い軌道のまま置き去りにされないように） |

- 時間制の効果は画面左上に「拡大 8s」のように残り秒数が出ます。
- 反対の効果（拡大↔縮小、スロー↔加速、パドル加速↔パドル減速）は取り消し合います。
- ボールを落とす（ミス）と、落下中のアイテムと効果、溜め撃ちのゲージはリセットされます。ただし**★スター効果中はそもそもミスになりません**。

## 溜め撃ち（パワーヒット）

**Shiftキーを押しっぱなし**にすると、パドルの少し上にあるゲージが溜まっていきます。キーを離すと
ゲージはすぐ0に戻るので、パドルに当たるまで押し続けてください。ゲージが一定以上（目安6割）溜まると
**パドル自体がピンク〜赤みがかった色**に変わり、「もう撃てる」ことを教えてくれます。

その状態でボールをパドルに当てると、パワーヒットが発動します。

- パドルがくっきりした**赤**になり、赤いパーティクルが飛び散る
- ボールが次のブロックを**2つまで、跳ね返さずに連続で破壊**（貫通アイテムと同じ「すり抜け」の仕組みを利用）
- 発動直後の一瞬だけ、ボールが**普段より速く**飛ぶ（すぐ元の速さに戻ります）

パドルに当たるたびにゲージは0に戻るので、次のパワーヒットにはまた溜め直しが必要です。
さらに、パワーヒットを発動すると**約10秒のクールダウン**が入ります。クールダウン中はShiftを押してもゲージが溜まらず、
ゲージの横に「あとXs」と残り時間が表示されます。

ゲージが発動ライン以上たまっている間は、パドルが**ブルブルと小刻みに震え**、「もう撃てる」ことをさらに分かりやすく伝えます。

ボールをパドルで弾いたときは、パドルが**実際に少し後ろへ押し戻されます**（ノックバック）。前に出て戦うほど押し戻されるので、
位置取りの駆け引きが生まれます。ただし**後ろの限界（初期位置）にいるときはそれ以上下がりません**（現状維持）。
**ボールが速いときほど押し戻される量も大きく**なり、パワーヒットのときはさらに大きくなって、より強く弾き返した感じが出ます
（押し戻し量には上限があるので、どれだけ速くても暴れすぎることはありません）。

## 自分で改造してみよう

`game.js` の中ほどにある **`CONFIG`** の数字を変えると、難しさや見た目が変わります。

| 変えたいこと | 場所（CONFIG の項目） |
| --- | --- |
| ボールの速さ | `ballSpeed` を大きく／小さく |
| パドルの幅・速さ | `paddleWidth` / `paddleSpeed` |
| ブロックの数 | `brickRows`（行）/ `brickCols`（列） |
| ブロックの行数の上限 | `brickMaxRows`（これ以上ステージが進んでも増えない） |
| 最初の残機 | `startLives` |
| ステージごとの加速 | `speedUpPerStage` |
| ボール速度の上限 | `ballSpeedCap`（これ以上ステージが進んでも基礎速度は増えない） |
| アイテムの落ちやすさ | `itemDropChance`（0〜1。0.3=30%） |
| アイテム効果の長さ | `effectSeconds`（秒） |
| アイテムの落ちる速さ | `itemFallSpeed` |
| 貫通の効果時間 | `pierceSeconds`（秒） |
| スター（無敵+加速）の効果時間 | `starSeconds`（秒） |
| 誘導アイテムの効果時間 | `homingSeconds`（秒） |
| 誘導アイテムの曲がる速さ | `homingTurnRate`（ラジアン/フレーム。小さいほど緩やか） |
| 大玉の大きさ | `bigBallScale`（倍率） |
| 溜め撃ちが満タンになる時間 | `chargeFullSeconds`（秒） |
| パワーヒット発動に必要な溜まり具合 | `chargeThreshold`（0〜1） |
| パワーヒットで壊せるブロック数 | `powerBrickCount` |
| パワーヒット直後の加速時間・倍率 | `powerBoostSeconds` / `powerBoostMult` |
| パワーヒットのクールダウン時間 | `powerCooldownSeconds`（秒） |
| パドルの前後移動の速さ | `paddleVertSpeed` |
| パドルが前に出られる上限 | `paddleForwardRatio`（0〜1。画面の高さに対する割合。0.667=下側1/3まで） |
| パドルの反動の大きさ（通常/パワーヒット） | `paddleRecoilBase` / `paddleRecoilPower` |
| 反動の上限・戻る速さ | `paddleRecoilMax` / `paddleRecoilDecay` |
| 実際に後ろへ下がる量（0で無効） | `paddleKnockbackMult` |
| チャージ完了時の震えの大きさ | `paddleShakeAmp` |
| 各アイテムの出やすさ | `ITEM_WEIGHTS`（`ITEM_TYPES` の近く。数字が大きいほど出やすい） |
| 壊れないブロックが混ざり始めるステージ・最大数 | `indestructibleStartStage` / `indestructibleMaxCount` |
| 壊れないブロックが増えるペース | `indestructibleStagesPerStep`（このステージ数が経つごとに1個増える） |
| フラフラ障害物が出始めるステージ | `floatingObstacleStartStage` |
| フラフラ障害物の速さ・存在時間・揺れ幅 | `floatingObstacleSpeed` / `floatingObstacleLifeSeconds` / `floatingObstacleBobAmp` |
| フラフラ障害物の出現間隔（最短〜最長） | `floatingObstacleMinGap` / `floatingObstacleMaxGap` |
| デバッグ用ステージ選択で選べる最大ステージ | `debugMaxStage` |
| ランキングの保存・表示件数 | `rankingMaxEntries` |
| 残機ボーナスがもらえるスコアの間隔 | `lifeBonusScore` |
| コンボ1段あたりの追加得点 | `comboBonusPerHit` |
| ボスが出現する間隔 | `bossStageInterval` |
| ボスのHP（初期値・増加量・上限） | `bossBaseHp` / `bossHpPerDefeat` / `bossHpMax` |
| ボスの動く速さ（初期値・増加量・上限）・上下の揺れ幅 | `bossSpeed` / `bossSpeedPerDefeat` / `bossSpeedCapValue` / `bossBobAmp` |
| ボスが不規則に向きを変える間隔（最短〜最長） | `bossDirChangeMinSeconds` / `bossDirChangeMaxSeconds` |
| ボスが下へ突っ込む間隔・深さ・所要時間 | `bossDiveIntervalMinSeconds` / `bossDiveIntervalMaxSeconds` / `bossDiveDepth` / `bossDiveDurationSeconds` |
| ボス撃破時のスコアボーナス | `bossDefeatBonus` |
| パワーヒット中にボスへ与えるダメージ | `bossPowerHitDamage` |
| ボスが連続ダメージを受けない最短間隔（無敵時間） | `bossHitCooldownSeconds` |
| ボスがブロックを放出する間隔・数・場の上限 | `bossBlockIntervalSeconds` / `bossBlockCount` / `bossBlockMaxOnField` |
| ボス戦の障害物の同時出現数の上限 | `bossObstacleMaxCount` |
| 背景の星の数 | `starfieldCount` |

ブロックの色は `CONFIG` のすぐ下にある **`BRICK_COLORS`** の配列を書き換えると変わります。

> **開発者向け（デバッグ）**: スタート画面で **D** キーを押すと、開始ステージを選ぶデバッグパネルが出ます（**↑↓** で選択、**スペース**で開始）。ゲーム画面には案内を出していない開発者用の隠し機能で、障害物（ステージ3・5〜）など、ステージが進まないと出ない要素の動作確認に使います。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | HTML・CSSだけの骨組み。`game.js`→`tutorial.js` の順に読み込む |
| `game.js` | ゲーム本体（設定・状態・物理演算・描画・音） |
| `tutorial.js` | チュートリアルモード。`game.js` の仕組みをそのまま使う「上乗せレイヤー」 |

`<script src="...">` による普通の読み込み（モジュールではない）なので、`index.html` を直接ダブルクリックして開くだけで動きます。

## コードの読み方（学習メモ）

**`game.js`** は、上から次の順番で並んでいます。

1. 設定（`CONFIG` / 色）
2. ゲームの状態（`game` … 今どうなっているかを全部持つ）
3. 音（`beep` などの効果音）
4. 配置し直す関数（`resetPaddle` / `resetBall` / `buildBricks`）
5. 入力（キーボード）
6. **更新** `update()` … 動きを1コマ進める（当たり判定もここ）
7. **描画** `draw()` … 今の状態を絵にする
8. **ループ** `loop()` … 「更新 → 描画」を毎フレーム繰り返す

「更新 → 描画 をひたすら繰り返す」のがゲームの基本の仕組みです。

**`tutorial.js`** は、`TUTORIAL_STEPS`（手順の一覧）と、それを進行させる数個の関数だけの、小さなファイルです。
ボールやパドルの動き・アイテムの仕組みは `game.js` のものをそのまま呼び出しているので、
「本編のコードを変えずに、別の遊び方を上に乗せる」書き方の一例としても読めます。
